# 插框测试上位机功能说明（工序1~工序4）

## 0. 近期修改与新增功能（汇总）

以下为本轮迭代相对上一版文档的主要变更，便于联调与验收对照。

### 0.1 MES 检查开关

| 项 | 行为 |
| --- | --- |
| **MES检查=开** | 条码校验、`GetProgramFile`、`SaveTestData` 走 MES；本地 `MES上传汇总.xlsx` 各工序表带 MES 表头（条码/作业ID/生产任务等） |
| **MES检查=关** | **不弹** MES 失败 MessageBox；跳过条码校验、取程序、服务器上传；本地 txt / `MES上传汇总.xlsx` **仍写入**（无 MES 表头） |

### 0.2 MES上传汇总.xlsx（新增/重构）

- 路径：程序目录（`bin`）下 `MES上传汇总.xlsx`
- 四个工作表：`工序1-安规测试` / `工序2-温湿度时间同步` / `工序3-告警测试` / `工序4-参数校准`
- 列：工序备注列 + `ITEM` / 项目列 / `TESTVALUE` / `MIN SPEC` / `MAX SPEC` / `UNIT` / `RESULT` / `TEST_REMARK`
- 关键实现：`Mes/MesUploadWorkbookWriter.cs`、`Mes/MesHeaderInfo.cs`；工序结束与告警/传感器/校准抓包均可追加
- **多版本说明**：当「MES开/关」与文件是否带表头不一致，或旧表结构不匹配时，会自动备份为 `MES上传汇总_旧格式_yyyyMMdd_HHmmss.xlsx` 再重建。日常以当前 `MES上传汇总.xlsx` 为准；旧格式备份可手动清理。少切换 MES 开关可减少备份数量

### 0.3 停止按钮与防卡死

- 停止顺序：先 `Cancel` → `Pause` 总线 → 短延时 → 再发停止包（带超时）→ UI 收尾；避免与轮询抢锁卡死
- 工序1 停止时跳过自动解除远程（由 UI 停机路径处理）
- UI 热路径改为 **`BeginInvoke`**（日志/数据更新/工序结束/模块高亮/监控窗），避免同步 `Invoke` 与 Modbus 锁死锁
- Modbus 监控窗日志改为 `BeginInvoke`
- 断开 MC2900：`SerialPort.Close` 放到后台线程
- 关窗：先 Pause 再关口；关闭时不做同步 Excel 重写
- 停止请求后：跳过 MES/汇总表上传与工序3待写告警落盘，加快退出
- 工序4 SNMP 写表改在后台线程；轮询失败改为写日志，避免定时弹窗堵 UI
- xlsx 写入加全局锁，防止多线程同时改写损坏

### 0.4 工序3 告警轮询提速与稳定

- **DI / SPD 每轮优先**：读完立即刷新指示灯
- **分组轮转**：负载熔丝+LVD、BAT、DO 分相查询，避免整轮长阻塞
- 按协议 **分项 FC01/FC03** 查询（不做跨地址合并，降低设备 `0x04` 故障）
- 遇从机故障 `0x04/0x06`、CRC 错误：软退避重试；连续异常达上限仍 FAIL 停测
- 告警落盘延后到本轮通信完成后；停止中清空待写队列

### 0.5 通信异常用户提示（新增）

- CRC 失败：弹窗标题「通信校验失败」，含排查步骤；**60 秒内最多弹 1 次**（`ModbusUserAlert`）
- 重连 MC2900 或重新开始测试会重置 CRC 弹窗冷却
- 从机异常封装为 `ModbusSlaveException`；CRC 封装为 `ModbusCrcException`

### 0.6 工序4 显示

- SNMP Measure 整数按 **÷10** 显示，格式 **`0.00`**

### 0.7 相关新增/重点文件

| 文件 | 说明 |
| --- | --- |
| `Mes/MesUploadWorkbookWriter.cs` | 四工序汇总 xlsx 写表 |
| `Mes/MesHeaderInfo.cs` | MES 表头信息 |
| `Communication/ModbusUserAlert.cs` | CRC 等用户弹窗（防刷屏） |
| `Communication/ModbusRtu.cs` | `ModbusSlaveException` / `ModbusCrcException` |

## 1. 总体说明

当前界面页签与后台流程的实际对应关系如下：

| 页签序号 | 界面名称 | 后台流程类 | 说明 |
| --- | --- | --- | --- |
| 工序1 | 安规测试 | Process1Safety | 长盛安规仪 ASCII 自动测试 |
| 工序2 | 温度/时间同步/模块通信 | Process2Software | MC2900 温度、时间；模块在线与上下电辅助 |
| 工序3 | 告警测试 | Process3Alarm | FC01 分项告警 + DO/LVD/BLVD 控制 |
| 工序4 | 参数校准 | Process5Power | SNMP OID 查询 + 参数校准 K/B 写入与复位 |

说明：

- 当前版本仅保留工序1~工序4，原工序5「上下电测试」相关界面、流程和驱动遗留已经移除。
- 工序3 页签绑定 **Process3Alarm**（工程编译该文件；旧文件 `Process4Alarm.cs` 为遗留，勿再当主流程）。
- 工序4 页签绑定 Process5Power（历史命名）；已改为手动参数校准，不再串口轮询 Modbus 校准寄存器。
- 工序1 使用安规仪串口；工序2~3 使用 MC2900 Modbus RTU；工序4 使用 SNMP UDP:161。
- 公共能力：`ProcessBase` 支持 `CancellationToken` + `DelayWithStopCheck`；工序2/3 连续通信异常达 5 次自动停止并记 FAIL。
- 顶栏 **MES检查** 开关控制是否走 MES 服务器；本地汇总表始终可写（见第 0 节）。

### 2.2 自动流程实现

自动流程顺序：

1. 绝缘测试
2. 交流对地测试
3. 接地电阻测试

每段测试完成后，把回包解析结果写入对应数据框，并保存原始回包 HEX 供 MES 上传。

### 2.3 查询包与设置包

ASCII 控制/设置指令完整发送包：

| 动作 | ASCII | 完整发送包(Hex) |
| --- | --- | --- |
| 进入远程模式 | COMM:REM | 43 4F 4D 4D 3A 52 45 4D CA 0D 0A |
| 解除远程模式 | COMM:LOC | 43 4F 4D 4D 3A 4C 4F 43 C4 0D 0A |
| 启动测试 | SOUR:TEST:STAR | 53 4F 55 52 3A 54 45 53 54 3A 53 54 41 52 B7 0D 0A |
| 停止测试 | SOUR:TEST:STOP | 53 4F 55 52 3A 54 45 53 54 3A 53 54 4F 50 C3 0D 0A |
| 复位 | \*RST | 2A 52 53 54 A3 0D 0A |
| 查询最新样本 | SOUR:TEST:FETCH? | 53 4F 55 52 3A 54 45 53 54 3A 46 45 54 43 3F DE 0D 0A |

自动流程行为：

- 开始前先尝试复位两次，只有收到 `+0,"No error"` 成功回包才记录「复位成功」。
- 然后发送一次远程模式指令。
- 每个阶段发送一次启动测试指令；连续查询 8 次样本。
- 自动流程完成后发送一次解除远程指令。

独立测试行为：

- 交流对直流 / 直流对地单测：启动 → 按步骤码查询 → 结束后解除远程。

## 4. 工序3：告警测试（防雷器 / 熔丝 / DI / DO / LVD / BLVD）

### 4.1 界面告警灯（已按流程拆分）

| 分组 | 灯控件 | DataUpdate | 数据来源（FC01 + CRC） |
| --- | --- | --- | --- |
| 防雷器 | AC SPD 告警、DC SPD Alarm | 201~202 | 线圈 `0x0565`、`0x0566` 各 1 位 |
| 蓄电池熔丝 | BAT1~BAT8 | 240~247 | `0x001C`×2 → BAT1~2；`0x10AF`×6 → BAT3~8 |
| 负载熔丝 | LLVD1~LLVD4 | 250~253 | 线圈 `0x0002` 起 4 位 |
| DI | DI1~DI8 | 210~217 | 线圈 `0x055D` 起 8 位 |
| DO | DO1~DO8 灯/状态 | 220~227 / 320~327 | FC03 读保持寄存器 6455 起 8 个 |
| LLVD/BLVD | LVD1~4 + BLVD | 230~234 / 330~334 | 线圈 `0x0007` 起 5 位 |

灯态规则（SPD / 熔丝）：回包数据字节 **00=无告警绿灯，非0对应位=有告警红灯**。测试未开始或未知态为灰色（`unknown`）。

### 4.2 主告警 / DI / 熔丝查询包

| 功能 | 协议 | 完整发送包(Hex) | 说明 |
| --- | --- | --- | --- |
| DI1~DI8 | FC01 | 01 01 05 5D 00 08 … | `0x055D`×8 |
| AC SPD | FC01 | 01 01 05 65 00 01 ED 19 | `0x0565`×1 |
| DC SPD | FC01 | 01 01 05 66 00 01 1D 19 | `0x0566`×1 |
| 负载熔丝 LLVD1~4 | FC01 | 01 01 00 02 00 04 9C 09 | `0x0002`×4 |
| 蓄电池 BAT1~2 | FC01 | 01 01 00 1C 00 02 7C 0D | `0x001C`×2 |
| 蓄电池 BAT3~8 | FC01 | 01 01 10 AF 00 06 88 E9 | `0x10AF`×6 |
| LVD1~4 + BLVD | FC01 | 01 01 00 07 00 05 4D C8 | `0x0007`×5，当前状态解释 0=ON / 1=OFF |
| DO1~DO8 状态 | FC03 | 01 03 19 37 00 08 F2 9E | 6455 起 8 寄存器；0 红灯 / 1 绿灯 |

后台轮询策略（已优化）：

- **每轮必检**：DI + AC/DC SPD（分项查询），读完立即刷新灯。
- **轮转项**：负载熔丝+LVD/BLVD → BAT → DO，组间约 **120ms** 稳定间隔。
- 遇 `0x04/0x06` 从机故障或 CRC：退避约 **300ms** 后继续；连续异常 **5** 次 → 自动停测 FAIL。
- 底层 `ModbusRtu`：组帧、附加 CRC16、收包校验；CRC 失败触发用户弹窗（见第 0.5 节）。

### 4.3 DO / LVD 控制与清除

工序3开始/停止切手动模式：

| 动作 | 协议 | 完整发送包(Hex) |
| --- | --- | --- |
| 进入手动模式 | FC05 | 01 05 00 15 00 00 DC 0E |
| 退出手动模式 | FC05 | 01 05 00 15 00 01 1D CE |

DO 按钮：FC06 写寄存器 6455~6462；写后立即回读。  
LVD1~4 / BLVD：FC05 写线圈 14~18；写后立即回读 `0x0007` 起 5 位。  
清除记录 / 清除模块告警：FC05 写线圈 `0x0001` / `0x0000`。

按钮点击前暂停告警轮询（`IsQueryPollingSuspended`），避免查询与设置冲突。

### 4.4 DO / LLVD 界面元素

每一路 DO、LVD、BLVD 均含：圆灯、当前状态标签、切换按钮。

### 4.5 数据更新对应（汇总）

| DataUpdate 代码 | 对应控件 |
| --- | --- |
| 201~202 | AC SPD / DC SPD |
| 240~247 | BAT1~BAT8 |
| 250~253 | LLVD1~LLVD4 |
| 210~217 | DI1~DI8 |
| 220~227 | DO 区域灯 |
| 230~233 / 234 | LVD1~4 / BLVD 告警灯 |

### 4.6 可靠性（优化）

- 连续通信异常 **5** 次 → 自动停止本次工序3，结果 FAIL。
- 告警触发时记录原始收发帧，并汇总到 MES 上传内容 / 本地 xlsx。
- 停止中不再刷写告警 Excel，避免「停止中」长时间卡住。

## 5. 工序4：参数校准（SNMP OID 查询/设置）

### 5.1 模式说明

工序4 为手动校准：不启动串口查询线程；确认设备 IP 后按 **3s** 周期 SNMP GET 填充 Measure；保存时 SNMP SET。

若未做有效校准会话即结束/上传路径要求空会话判定：**FAIL**，并跳过无效 `SaveTestData`（避免空结果当成功）。

### 5.2 界面控件

| 控件 | 作用 |
| --- | --- |
| 设备IP | 输入 SNMP Agent；确认后锁定并启动轮询 |
| 读 Community | 默认 `PowerPublic`，确认时锁定供 GET |
| 写 Community | 默认 `PowerPrivate`，确认时锁定供 SET/复位 |
| 确认 / 解锁 | 启动或停止轮询并解锁输入 |
| 参数表 19 行 | Measure / Actual / Point(K or B) / **复位** / 保存 |
| 顶栏结果徽章 | **仅工序4** 显示「结果」列 |

注释屏蔽行（代码保留）：温度1~5、环境湿度、DG Fuel Cap、输入电压/电流 L1~L3。

### 5.3 操作限制

1. 条码必填后才能开始。
2. 开始测试后才可编辑 IP/Community；锁定后只读。
3. 运行中切换到其他页签须先停止；停止会解锁 IP、停轮询、重置校准控件。

### 5.4 复位按钮（新增）

每行「复位」与「保存」共用 SET OID（写 community）：

- 参数名以 **B** 结尾：写入 **0**
- 其余（K 及电压类系数）：写入 **1000**

成功/失败更新结果徽章；异常信息写入运行日志（避免轮询/SET 路径过度弹窗卡 UI）。写入前后记监控与 MES 相关原始说明。

### 5.5 SNMP 查询 OID（Measure）

| 行 | 参数名 | 查询 OID |

| 1 | 电池1电压 | .1.3.6.1.4.1.40211.3.1.1.2.0 |

## 6. 数据监控功能

### 6.1 能力

- 端口类型：安规 / MC2900 / **SNMP**（`ModbusDataLogger.PortType`）。
- 监控窗筛选含 SNMP；图例紫色标识 SNMP。
- SNMP GET/SET/RESP 实时写入监控。
- **仅窗口打开时采集**；关闭后不累积；再次打开从空白开始。
- 清空只清当前监控会话，不抹全局缓存。
- 监控窗刷新使用 **BeginInvoke**，避免在总线锁内同步 Invoke 导致卡死。

### 6.2 端口颜色

| 端口 | 发送 | 接收 |
| --- | --- | --- |
| 安规测试仪 | 橙色 | 浅橙 |
| MC2900 | 青色 | 浅青 |
| SNMP | 紫色 | 浅紫 |
| 信息 | 黄色 | — |

## 7. 公共工程与可靠性优化（汇总）

| 项 | 说明 |
| --- | --- |
| 流程编译绑定 | 工序3 使用 `Process3Alarm.cs`；校正历史误绑 |

| 通信熔断 | 工序2/3：连续 5 次通信异常 → 自动停测 FAIL |

| 本地汇总表 | `MES上传汇总.xlsx` 四工序表；开/关切换可能导致「旧格式」备份 |
| CRC 提示 | 60s 内最多弹一次排查指引 |
| 南向串口 | TX FIFO + 2s 超时 UI 提示 |
| 工序4 空会话 | 无有效校准时 FAIL，跳过无效 MES 保存 |
| UI 主题 | 统一主色/危险色/状态灰；工序4 独占结果徽章列 |

## 10. 维护建议

1. 先在 MainForm 确定控件与 DataUpdate 编码。
2. 再在 Process 类补查询轮询并推送编码。
3. 写操作封装到 `MC2900Driver` 或 `SnmpV2cClient`；写后立即回读。
4. 工序3 新增告警位：在 `MC2900Driver` 增加 FC01 读方法 → `Process3Alarm` 轮询发布 → MainForm 绑定灯与编码。

6. 汇总表列/表头变更时改 `MesUploadWorkbookWriter`；注意 MES 开关与「旧格式」备份行为。
7. 文档与代码冲突时以 `程序测试流程.txt` 报文与当前绑定类为准，并同步改本 README。
